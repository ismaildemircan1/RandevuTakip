## 2024-04-24 - Debouncing DOM events\n**Learning:** When attaching event listeners to input elements in vanilla JavaScript that execute Firebase read operations, it is crucial to debounce the input event. An un-debounced event listener fires on every single keystroke, causing rapid, successive database queries. This can lead to significant UI blocking, memory leaks, and most importantly, exhausting the database quota or rate limits.\n**Action:** Whenever working with search input events that query remote databases like Firebase/Firestore, immediately wrap the database query logic inside a `setTimeout` debounce function to improve performance and stability.
