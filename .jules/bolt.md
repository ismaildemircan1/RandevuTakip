## 2024-05-18 - Eliminated unnecessary network calls on search\n**Learning:** Found an `input` event listener that triggered a full Firestore database collection query on every keystroke. This causes massive latency and high database read costs.\n**Action:** Always check event listeners for high-frequency events (like `input`, `scroll`, `mousemove`). Ensure they either use debouncing or, ideally, filter against an already-fetched local state cache instead of hitting the network.
